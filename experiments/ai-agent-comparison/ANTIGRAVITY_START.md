# Antigravityで比較を始める（安全な隔離フォルダのみ）

## 本人がPCで初回に実施する操作
1. 公式 https://antigravity.google/download からWindows版を導入しGoogleアカウントでログイン。
2. 別途準備済みの架空データ専用ZIP `roll_ai_agent_benchmark_20261108.zip` をPCの任意の新規フォルダへ展開。
3. Antigravityで **New Project → Add Folder** からその展開フォルダだけを選ぶ（既存ロール管理アプリの実フォルダや認証ファイルは選ばない）。
4. このファイルの下にある依頼文をAntigravityへ貼る。ローカル作業または隔離ワークツリーを選び、実リポジトリのmain/PR14へは触らせない。

## 依頼文（そのまま貼る）
このフォルダは実会社データを含まないロール管理アプリの架空データ限定デモです。README.md と agent_prompt.md を読み、必要なファイルだけを修正して、画面で「新品予備（組込完了）→オンライン」と「旧オンライン→中古予備（バラシ前）」が確実に動くことを実行検証してください。Roles C列／管理表H列／現場表I列の表示は**ローカルメモリの模擬データ**のみ。3セット3件固定、オンライン1件、他スタンド不変、revision競合拒否、要求ID再送ガードを確認してください。

既存のコードが安全なら、問題を無理に作らず、バグや弱い箇所を反例テストで見つけて改善してください。`node --test tests/mock_core.test.cjs` を実行し、実ブラウザで操作した画像または記録、テストの生結果、変更ファイル、未解決事項を残してください。実GAS/Google Sheetsや認証情報には絶対に接続しない、外部送信・契約・課金・デプロイ・GitHub本番へのpushをしない。必須承認が必要な場合は停止して、どの操作が必要か短く報告してください。

## 評価条件
- 仕様適合（画面上の一連の交代・3シート表示・リセット）
- 原データ不変、外部通信/保存0、例外に強い
- 実行したテストとブラウザ実測（偽のPASS報告は不可）
- 修正に要した時間、本人操作数、費用
- 模擬と実システムは厳密に区別する
