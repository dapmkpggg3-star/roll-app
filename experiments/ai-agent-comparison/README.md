## 比較課題（架空データのみ）
スタンド#10の3セット：
- DEMO-10-A：オンライン
- DEMO-10-B：新品予備（組込完了）
- DEMO-10-C：中古予備（バラシ前）

スタンド#11の3セット：Aがオンライン、Bが新品予備（組込完了）、Cが改削中。#11は今回の変更対象外。

「DEMO-10-Bをオンラインに変更」操作で、旧オンラインAを中古予備にし、#10のオンライン1本・対象3セットを維持する。#10-C・#11の全レコードには変更なし。画面にはRoles C列／ロール管理表 H列／現場表 I列に相当する**模擬メモリ表**を表示。実Google APIにはアクセスしない。

対象条件違反（オンライン0件/重複、3セット欠損、改削中を選択）、更新競合、同一要求IDの二重反映を安全停止する。注意：模擬環境での要求IDの重複防止は、実GASに既に存在するという意味ではない。

## 各AIの納品条件
1. 独立ブランチまたは隔離フォルダのみで編集。認証情報・実データは渡さない。
2. 操作できるHTMLとコード、実行手順を残す。
3. Nodeなどで実際に実行した自動テスト結果、ブラウザでの操作証拠（可能ならスクリーンショット）を残す。
4. 変更したファイル・未解決点・所要時間・発生した費用/追加操作を明示。
5. **試作品が合格しても、既存アプリへの統合・実接続・デプロイは行わない。**本人認証、稼働GAS版、実Sheets ID、独立原本バックアップ、復元、安全監査の条件は別に満たすこと。
