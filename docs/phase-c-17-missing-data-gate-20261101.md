# Phase C #17 — Missing Data Gate

更新日: 2026-11-01

## 目的

Phase Cが不足情報を一度に全部要求せず、
「今の次サイクル判定に必要」
と
「12か月判定に必要」
を分けて扱う。

## A. 今の次サイクル判定に必要

### 1. 17-89 カリバ別実累計
理由:
- #17 D10/D13とも各カリバ累計最大6直。
- remaining shiftsを計算するにはactual cumulativeが必要。
- planned 59直をactualへ昇格しない。

### 2. 17-90 10/26戻り後の実測径
理由:
- Rolesの338.0は6/8登録。
- latest rework rowにも338.0表示はあるが、Rolesに径更新履歴がなく、初回照合資料でも戻り後実測未確認扱い。
- ready spareの径適合を確定できない。

### 3. 17-90 組込完了実績
理由:
- 現在は新品予備（組替可能）。
- 17-88→17-90の組替候補はあるが、実績として組込完了になるまでready spareとして確定しない。

## B. 12か月判定に必要

### 1. 2026-12-10より先の生産／カリバ使用見込み
現在のplanned coverageは12/10まで。
12/10は使用終了日・交換日ではない。

### 2. サイクルごとの使用量接続
各カリバ最大6直を、actual + future plannedへ接続する。
番号順に自動消費しない。
D10ペアとD13単独を分ける。

### 3. 将来の改削戻りと組替準備
径が足りても、
- 搬出
- 約25日改削
- 戻り
- チョック組替
- 組込完了
が次回必要日に間に合うかを別判定する。

## C. 今すぐ必須ではない

- 17-89前回2.00mm減径の通常/フラット区分
- 17-90今回加工の通常/フラット区分

実測径を確定入力できれば直近判定は可能。
ただし履歴分析と二重減径防止の検証には有用。

## D. 17-91の扱い

16,17履歴表に
- 17-91
- 340mm
- 2026年度予算計上予定
の参考記録あり。

ただしRolesに17-91は存在しない。

よって:
- 現在在庫に数えない
- 4セット目に数えない
- ready spareに数えない
- shortage回避の根拠にしない
- 将来購入検討のreferenceとしてのみ保持

## E. UI要求方針

不足情報を表示する場合:
- 今の次サイクルに必要な3点を上位
- 12か月判定用をその次
- optionalは折りたたみ/補足

本人に入力を求めるのは、既存資料・連携データから取得できないと確認した項目だけ。
